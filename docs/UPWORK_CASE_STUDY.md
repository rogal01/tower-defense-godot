# Upwork Case Study

## Suggested Title
Godot Tower Defense Prototype Focused On UX, Iteration, And Mobile HUD Design

## Suggested Cover Image
HUD-heavy gameplay screenshot with wave preview, map area, and polished mobile-friendly menu state.

## Challenge
Explore the same tower defense product space inside a fast-iteration engine workflow, with special attention to onboarding, save flow, and combat readability.

## Solution
I built the project in Godot 4 with scene composition, autoload-based state systems, save support, tutorial overlays, and mobile-first HUD flows. The repo is designed to show fast feedback loops and engine-first experimentation without losing project structure.

## Impact
This project proves quick prototyping, strong UX iteration, and the ability to keep a game project understandable while refining player-facing systems.

## Why This Matters To Clients
It shows that I can move quickly in a modern engine, improve usability without overengineering early stages, and keep the codebase organized enough for future scaling.
